Cream Beans — Admin & Security Dashboard

The Cream Beans Admin & Security Dashboard helps campus staff manage lost-and-found cases from one place.

It is designed around a simple goal: help staff find, verify, and return items faster.

Key Features
Dashboard

A quick overview of the campus lost-and-found system:

Total lost reports
Total found reports
Active cases
Matched cases
Returned items
Recovery rate
Found Items

Staff can view and filter found items by:

Category
Location
Status

Each report includes the item image, description, location, time, reporter, and current status.

Item Details

Staff can open a case to see all relevant information, including:

Item and reporter details
Image
Current status
Potential match information
Match Inspection

Instead of relying only on keywords, Cream Beans considers multiple factors when identifying a potential match:

Image similarity
Text similarity
Location
Time
Final match score

This gives staff a clearer understanding of why two reports may be considered a match.

Case Tracking

Cases move through a simple workflow:
Active → Matched → Returned
