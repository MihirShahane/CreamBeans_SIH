# Project Specification

## Project Name
**Where have you bean?**

## Problem Statement
The existing systems for finding and locating the lost objects are manual and unsearchable and rely heavily on the response by other users. We solve this problem by integrating an AI platform which analyzes the lost and found reports to provide with a score that helps to determine if the found object is a match for a lost object.

## Objective
Help to minimize the hassle faced while finding a lost object. 
Identifying likely hotspots for loosing objects and improving on it.
